## 1. どのブランチから始めるかを決める

このリポジトリは、道具の組み合わせごとに、ブランチを分けています。考え方は、[Architecture](./03_ARCHITECTURE.md) の「1. ブランチの考え方」を参照してください。

| 始め方 | 使うブランチ | 向いている場面 |
| --- | --- | --- |
| 道具が入った状態から始める | `example/` で始まるブランチ | 使いたい組み合わせに近いブランチがある。ふつうは、こちらを使います |
| 何も入っていない状態から始める | `main` | 道具を、自分で選んで入れたい。組み合わせのブランチに、近いものがない |

組み合わせのブランチの一覧は、[README](../README.md) の「Branch」にあります。

`main` から始める場合は、スタイル、コードの検査、単体テストの道具が、何も入っていません。組み合わせのブランチを、入れ方の手本として見てください。

## 2. 自分のリポジトリを作る

1. GitHub で、[このリポジトリのページ](https://github.com/ike-keichan/sandbox-nextjs)を開きます。
2. 右上の「Use this template」を押し、「Create a new repository」を選びます。
3. リポジトリの名前と、公開範囲（Public か Private）を決めます。
4. 始めるブランチに合わせて、次のどちらかを選びます。

   | 始めるブランチ | 「Include all branches」 |
   | --- | --- |
   | `main` | チェックしない |
   | `example/` で始まるブランチ | チェックする |

5. 「Create repository」を押します。

`example/` で始まるブランチから始めた場合は、作ったリポジトリで、そのブランチを `main` にします。

```zsh
$ git clone <作ったリポジトリの URL>
$ cd <作ったリポジトリの名前>
$ git switch <使うブランチ>
$ git branch -M main
$ git push --force origin main
```

そのあと、使わないブランチは、GitHub の画面（「Branches」のページ）から消してください。

「Use this template」で作ったリポジトリは、このリポジトリの履歴を引き継ぎません。

## 3. 手元に持ってきて、動くことを確かめる

名前を変える前に、まず、そのままで動くことを確かめます。

[Getting Started](./01_GETTING_STARTED.md) の手順を、「3. 環境を作る」から進めてください。

<http://localhost:3000> が開けたら、次へ進みます。

---

## 4. 名前を変える

`sandbox-nextjs` という名前を、自分のプロジェクトの名前に変えます。

| ファイル | 変える場所 | いまの値 |
| --- | --- | --- |
| `package.json` | `name` | `sandbox-nextjs` |
| `package.json` | `description` | `Next.js のプロジェクトのひな形` |
| `src/app/layout.tsx` | `metadata` の `title` と `description` | `sandbox-nextjs`、`Next.js のプロジェクトのひな形` |
| `README.md`、`readme/` | 題名、説明、URL | |

コンテナの名前は、フォルダの名前から自動で付きます。手で変える必要はありません。

---

## 5. ページと API を足す

ファイルの置き方は、[Architecture](./03_ARCHITECTURE.md) の「3. ページと API の置き方」を参照してください。

足したら、確かめます。

```zsh
$ make js/typecheck
$ make js/build
```

あわせて、[scripts/smoke.sh](../scripts/smoke.sh) に、足したページや API を呼ぶ行を足してください。自動テストで、起動したサーバーが応答することを確かめられます。

---

## 6. 不要なものを消す

自分のページができたら、見本は消してかまいません。

| 消すもの | 場所 |
| --- | --- |
| API の見本 | `src/app/api/hello/` |
| 起動の確認の呼び出し | `scripts/smoke.sh` の `/api/hello` を呼ぶ行（自分の API のパスに変える） |

`src/app/page.tsx`（トップページ）は、消さずに、中身を自分のものに書き換えてください。

`readme/` の文書も、自分のプロジェクトに合わせて書き換えてください。
