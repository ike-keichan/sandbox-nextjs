# Command（コマンド）

よく使うコマンドは、[Makefile](../Makefile) にまとめています。`make <名前>` の形で実行します。

- [1. コンテナの操作](#1-コンテナの操作)
- [2. 型の検査とビルド](#2-型の検査とビルド)
- [3. パッケージの操作](#3-パッケージの操作)
- [4. コンテナの中に入る](#4-コンテナの中に入る)

※ コマンドは、このリポジトリのフォルダの直下で実行してください。

※ `js/` と `node/` で始まるコマンドは、開発用のサーバーが起動していなくても使えます。実行のたびに、別のコンテナを起動して、終わると止めます。

---

## 1. コンテナの操作

| コマンド | 内容 |
| --- | --- |
| `make setup` | 環境を作ります（ビルド、パッケージのインストール）。初回だけ使います |
| `make up` | 開発用のサーバーを起動します。記録がターミナルに出続けます。`Ctrl + C` で止まります |
| `make upd` | 開発用のサーバーを、バックグラウンドで起動します。起動が終わるまで待ちます |
| `make stop` | サーバーを止めます |
| `make restart` | サーバーを再起動します |
| `make build` | コンテナをビルドし直します。`Dockerfile` を変えたときに使います |
| `make ps` | コンテナの状態を表示します |
| `make down` | コンテナと、インストールしたパッケージを削除します |

開発用のサーバーは、<http://localhost:3000> で開けます。

---

## 2. 型の検査とビルド

| コマンド | 内容 |
| --- | --- |
| `make js/typecheck` | TypeScript の型を検査します |
| `make js/build` | 本番用のビルドを行います。ビルドできることの確認に使います |

プルリクエストを作る前に、`make js/typecheck` と `make js/build` を実行してください。

`main` ブランチには、コードの検査（ESLint など）と、単体テストは入っていません。組み合わせのブランチ（`example/` で始まるもの）で足しています。

## 3. パッケージの操作

| コマンド | 内容 |
| --- | --- |
| `make js/add TARGET=<パッケージ名>` | パッケージを追加します |
| `make js/add-d TARGET=<パッケージ名>` | 開発用のパッケージ（検査やテストの道具）を追加します |
| `make js/install` | `pnpm-lock.yaml` の記録のとおりに、パッケージをインストールします |
| `make js/outdated` | 新しいバージョンが出ているパッケージを表示します。何も表示されなければ、すべて最新です |

例：`zod` を追加する場合

```zsh
$ make js/add TARGET=zod
$ make restart
```

バージョンは、追加した時点のものに固定されます（`^` や `~` は付きません）。追加したあとは、`make restart` で、サーバーを再起動してください。

`git pull` で `package.json` や `pnpm-lock.yaml` が変わったときは、`make js/install` のあとに、`make restart` を実行してください。

---

## 4. コンテナの中に入る

| コマンド | 内容 |
| --- | --- |
| `make node/login` | コンテナのシェルに入ります。`exit` で抜けます |
| `make node/repl` | Node.js の対話環境を開きます。`.exit` で抜けます |

コンテナの中では、`pnpm` のコマンドを直接使えます（`pnpm typecheck`、`pnpm build` など）。続けて何度も実行するときは、中に入ったほうが、コンテナの起動を待たずに済みます。
